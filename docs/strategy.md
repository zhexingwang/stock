# 底値回復戦略（Mean-Reversion + Recovery Quality）

## コア思想

市場は短期に過剰反応しやすい。一時的ショック・サイクル悪化・コスト高で株価が過度に沈んだ企業のうち、**事業の回復力と財務の耐久力があるもの**を安値で持ち、ファンダメンタルまたは価格の正常化で利益を取る。

これは「安いから買う」ではない。**安い × 回復可能 × カタリスト** の積が揃ったときだけ候補にする。

## 戦略案の骨格

| 段階 | 問い | 主な指標 |
|------|------|----------|
| 1. 底の特定 | 本当に売られ過ぎか | 52週/2年高値比ドローダウン、対指数・対セクター相対リターン |
| 2. 生存確認 | 倒産・希薄化リスクは低いか | 現金、流動比率、純負債/EBITDA、利息被覆、希薄化履歴 |
| 3. 回復力 | 利益は戻せるか | 粗利率・営業利益率のボトムと反転、FCF、稼働率、在庫 |
| 4. カタリスト | 何が株価を動かすか | ガイダンス、政策、需給、コスト下落、リストラ完了 |
| 5. バリュエーション | 回復織り込みは薄いか | EV/Sales, EV/EBITDA, P/B, 過去レンジとの差 |
| 6. エグジット | いつ売るか | 目標バリュエーション到達、ドローダウン回復率、仮説崩壊 |

## エントリーの考え方

推奨は一括買いではなく、条件付きの分割。

1. **ウォッチ**: スクリーナー通過 + 開示確認前
2. **候補**: 財務OK + 仮説あり + カタリスト明確
3. **エントリー帯**: 直近安値近辺〜レンジ下限。業績確認後の押し目も可
4. **見送り**: 構造的シェア喪失、慢性的な現金燃焼、会計疑義、流動性枯渇

## 売却の考え方

- **利確**: 価格がドローダウンの一定割合を回復、またはバリュエーションが歴史的中央値へ回帰
- **部分利確**: ベースシナリオ達成で半分、強気シナリオで残り
- **損切り**: 仮説崩壊（追加増資で希薄化、主要顧客喪失、債務不履行懸念の顕在化）
- **時間損切り**: カタリスト期限を過ぎても指標が改善しない場合は再評価

## トップダウン・セグメント選定

世の中の動向から大きな箱を選び、その中で売られ過ぎを探す。

例（状況により更新）:

- 金利低下局面 → 成長株・不動産・高負債だがキャッシュフロー改善余地のある業種
- 半導体サイクル底打ち → 装置・素材・後工程
- エネルギー価格変動 → 上流/下流のマージン格差
- 防衛・インフラ政策 → 受注残と採算
- 内需回復/インバウンド → サービス・小売の稼働率

セグメント選定時は「テーマが正しいか」だけでなく「株価がすでに織り込み済みか」を必ず見る。

## アドバイス原則

1. ポジションサイズは回復不確実性に反比例させる
2. 一つのカタリストに全賭けしない
3. 同業比較なしに「割安」と言わない
4. 円建て投資家は為替と金利感応度を併記する
5. 短期材料株と、中期の事業回復株を混ぜない
